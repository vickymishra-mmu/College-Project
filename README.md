# DSA Visualizer Pro

A modern, animated, browser-based **Data Structures & Algorithms Visualizer** built with pure **HTML5, CSS3 and JavaScript**.

## Included modules

- Sorting: Bubble Sort, Selection Sort, Insertion Sort, Merge Sort, Quick Sort
- Searching: Linear Search, Binary Search
- Graph traversal: BFS, DFS
- Data Structures: Stack and Queue
- Start / Pause / Resume / Step / Reset / Randomize
- Adjustable animation speed
- Live execution log
- Best / Average / Worst / Space complexity panel
- Responsive dark futuristic UI
- Light/dark visual theme toggle
- Included project blueprint image in `assets/project-blueprint.png`

## Run locally

No installation or backend is required.

1. Extract the project folder.
2. Double-click `index.html`, or open it using VS Code Live Server.
3. Go to **Visualizer Lab** and choose an algorithm.
